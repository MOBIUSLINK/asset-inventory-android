# 产品与交互原则

1. 按用户目的组织功能，不按技术模块堆叠页面。
2. 首页首先支持开始/继续盘点，其次检查结果和完成交付。
3. 高频操作入口浅，低频管理能力放入侧边栏或对应对象详情。
4. 同一功能只设一个主要入口；摘要可进入对应明细，但不复制一套处理功能。
5. 页面只显示当前状态真正可执行的操作。
6. 返回遵循实际导航历史，保持思维连续性。
7. 空状态必须解释当前情况并提供最合适的下一步。
8. 创建、导入、删除、完成、归档和恢复后必须有明确反馈与下一步引导。
9. 能自动推断的内容不要求用户重复填写；任务名称默认自动建议。
10. 高频扫码不增加确认步骤；识别成功立即记录并用语音反馈。
11. 图标用于辅助理解，不能独自承载不明确的业务含义。
12. 动画用于表达层级和状态变化，不干扰连续操作。
13. 技术传输方式作为操作方式呈现，不能代替用户目的。
14. 危险操作明确显示对象、影响范围和恢复方式。
15. 功能可用性优先于视觉精修；真机表现优先于模拟预览。
