# 外部设备与文件集成

## Android 与权限

- minSdk 29，targetSdk 37。
- 使用相机扫码、蓝牙查找/配对/连接打印机、Android TextToSpeech、文件选择器与分享面板。
- 权限应在功能实际需要时请求；蓝牙未开启、权限未授予、设备未配对时主动解释并提供下一步。

## 语音播报

- 使用系统 TextToSpeech，优先兼容不同品牌手机现有语音引擎。
- 初始化失败或缺少中文语音时必须显示状态提示。
- 采用 `QUEUE_FLUSH`：新编号中断旧播报，只播最新编号。
- 语音是核心反馈，改动后必须真机连续扫描验证流畅度、完整性和杂音。

## NIIMBOT 打印

- 打印机：NIIMBOT B3S_P。
- 标签：T40×15。
- SDK：`app/libs/4.1.1-release.aar`、`image-1.9.5.aar`、`LPAPI-2019-11-20-R.jar`。
- SDK 二进制并非项目原创；公开再分发前需确认厂商许可。
- 打印必须真机检查：二维码可扫、上下居中、左右视觉间距、文字可读、连续多张不额外送空白标签。
- 未开启蓝牙时提示开启；未配对设备应能在打印界面发现并触发系统配对。

## 面对面传输

- 二维码展示的是局域网临时传输信息，接收端扫码后预览并确认导入。
- 网络变化、二维码刷新、服务停止和重连必须作为独立状态处理。
- 已知：部分一加设备连续多轮断开/重连 Wi-Fi 后，断网状态可能不立即刷新。

## Excel

- 台账从 `.xlsx` 导入；真实编号格式优先于理想化正则规则。
- 无法自动处理的导入行进入异常列表，允许人工修正后再导入。
- 已完成和已归档任务可导出 Excel 盘点总表。

## 离线文件

- `.invtask`：任务、公司、指定区域和所需台账信息。
- `.invresult`：扫码、处理信息和异常照片。
- `.invbackup`：完整数据库、异常照片、校验值和创建原因元数据。
- 文件导入必须先校验格式、版本和内容摘要，再由用户确认。
