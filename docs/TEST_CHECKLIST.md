## 每次版本必须执行

- [ ] Debug 构建通过。
- [ ] 单元测试通过。
- [ ] App 安装并正常启动。
- [ ] 当前公司和任务切换正确。
- [ ] 返回路径正确。
- [ ] 空状态有下一步引导。
- [ ] 操作完成有反馈并刷新页面。
- [ ] 未出现重复或丢失入口。
- [ ] 其他公司数据未混入当前页面。
- [ ] 版本号已更新并可在 App 中查看。

## 涉及扫码时

- [ ] 区域码、资产码和传输码识别正确。
- [ ] 无区域时提示扫描区域码。
- [ ] 连续扫描不需要确认。
- [ ] 最新语音中断旧语音且完整播报。
- [ ] 同区域重复、跨区域重复、台账外资产处理正确。
- [ ] 手电筒手动和自动状态正确。

## 涉及传输时

- [ ] 发送端二维码完整显示。
- [ ] 接收端先预览再导入。
- [ ] 重复导入不重复计数。
- [ ] 网络断开、重连、超时和返回均有反馈。
- [ ] `.invtask` 和 `.invresult` 文件分享、选择和导入正常。

## 涉及打印时

- [ ] 蓝牙关闭时主动提示。
- [ ] 未配对设备可以查找、配对和连接。
- [ ] 单张和连续多张打印正确。
- [ ] 不额外浪费空白标签。
- [ ] 二维码可扫，区域标签显示区域名称。

## 涉及删除或恢复时

- [ ] 明确显示对象和影响范围。
- [ ] 要求操作人与原因（适用时）。
- [ ] 保护性备份成功后才继续。
- [ ] 备份可预览公司、任务、原因和目标。
- [ ] 全量恢复前再次备份当前数据。
- [ ] 单公司恢复不影响其他公司。
- [ ] 单任务恢复不影响其他任务。
- [ ] 冲突时明确覆盖或取消，不静默生成副本。
- [ ] 异常照片能够随备份恢复。
