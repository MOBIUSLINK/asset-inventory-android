# 导航与功能入口

## 全局结构

- 顶部栏：显示当前公司；点击后切换公司、添加公司或进入当前公司资料维护。
- 侧边栏：盘点人员、资产与标签、任务管理、文件传输、备份与恢复等非当前主步骤入口。
- 首页：当前公司的开始/继续盘点、进度摘要、结果处理和下一步引导。
- 返回：使用应用内导航栈回到实际上一步；流程完成后才明确返回首页或对象主页。

## 主要入口清单

| 用户目的 | 主要入口 | 说明 |
|---|---|---|
| 新建/切换公司 | 顶部公司菜单 | 公司是全局上下文，不放在任务管理中 |
| 修改公司资料 | 顶部公司菜单 | 不与新建公司入口重复 |
| 开始/继续盘点 | 首页 | 应用最核心入口 |
| 查看当前进度 | 首页进度摘要 | 数字可直接进入对应明细 |
| 处理异常与重复 | 首页摘要或任务详情的同一目标页面 | 摘要是情境入口，不复制处理逻辑 |
| 管理区域和任务 | 侧边栏“任务管理” | 支撑盘点准备和历史任务查看 |
| 查看台账/打印标签 | 侧边栏“资产与标签” | 台账详情中的二维码可查看、分享和打印 |
| 面对面发送/接收 | 扫描主流程及交付流程 | 二维码是默认传输方式，接收前核对并导入 |
| 文件发送/导入 | 侧边栏“文件传输” | 用于飞书、QQ和文件管理器协作 |
| 导出 Excel | 已完成/已归档任务详情 | 历史任务仍可导出 |
| 备份与恢复 | 侧边栏 | 低频高风险管理能力 |

## 入口变更检查

新增或移动入口前必须回答：

1. 用户想完成的目的是什么？
2. 现有入口是否已能完成？
3. 新入口是主要入口还是情境快捷入口？
4. 在哪些状态下显示？
5. 是否会造成同义入口、功能丢失或跨公司数据混入？
6. 操作完成后返回哪里、显示什么反馈？
