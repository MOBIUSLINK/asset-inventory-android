# 状态与生命周期

## 盘点任务

### 进行中

- 可以扫码、处理异常和重复、接收盘点结果。
- 可以导出任务包和结果包。
- 只有不存在未处理跨区域重复和未完成异常时才能完成。
- 首页可以选为当前任务；同公司允许存在多个进行中任务。

### 已完成

- 不再接受普通扫码或结果合并。
- 可以查看结果、导出 Excel、归档或填写操作人与原因后重新开启。
- 完成后清除当前任务选择，并提示可以导出 Excel。

### 已归档

- 仍可查看历史结果和导出 Excel。
- 不应继续显示为当前盘点进度。
- 可以填写操作人与原因后重新开启。

## 扫码事件

- 首次在当前区域扫描：形成有效记录。
- 当前区域重复：提示重复，不计入该区域有效数量。
- 不同区域重复：各区域记录均有效，进入待处理；可能是设备移动，也可能是编号冲突。
- 台账外编号：保留有效记录并标记新增待入账。
- 撤销：保存撤销人、原因和时间，不物理删除扫码历史。
- 异常：需要类型/说明，可添加现场照片；未完整处理时阻止任务完成。

## 多设备交付

- 主手机创建任务，也可参与盘点。
- 其他手机通过任务包获得指定区域。
- 结果传输或文件合并前必须预览公司、任务、人员、区域、记录和照片。
- 重复结果不重复计入；“收到结果”不等同于该区域一定盘点完整。

## 删除与恢复

- 删除公司会删除该公司的区域、台账、任务、扫码记录和照片。
- 删除任务会删除任务区域、工作会话、扫码记录和照片。
- 删除前必须显示影响范围、要求多步确认，并先生成完整保护性备份。
- 完整恢复替换全部数据；公司/任务选择性恢复不影响其他范围。
- 任何恢复前先备份恢复前的当前完整数据。
